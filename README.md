# Accord for Dart and Flutter

**Offline-first sync that stays correct when the network lies**, for Dart and Flutter apps.

Apps keep working with no connection. When it comes back, every device ends up with the same data:
changes merge by rules you declare per field, counters never lose an increment, and conflicting
decisions are kept for your app to settle instead of being guessed.

These packages speak the same protocol and merge by the same rules as the
[TypeScript packages](https://github.com/crossben/accordsync), so Flutter and web or React Native
devices sync through the same server.

Website and docs: **[accord.benhattab.pro](https://accord.benhattab.pro)** · Flutter guide:
[accord.benhattab.pro/docs/flutter](https://accord.benhattab.pro/docs/flutter/)

```sh
flutter pub add accordsync_flutter drift_flutter
```

## Packages

| Package | What it does |
| --- | --- |
| [`accordsync_core`](https://pub.dev/packages/accordsync_core) | The merge core: hybrid logical clocks, operations, `lww`, `counter`, `set` and `conflict`. Pure Dart. |
| [`accordsync`](https://pub.dev/packages/accordsync) | The client: local-first writes, background sync, conflicts and refusals. Pure Dart, works in Flutter, CLI tools and servers. |
| [`accordsync_flutter`](https://pub.dev/packages/accordsync_flutter) | Storage on the device (drift), widgets for records, conflicts and sync status, and sync that follows the app lifecycle. |

## How we know it merges like the TypeScript packages

- `contract/` holds the golden vectors from the Accord repository; the Dart core passes every one in
  every delivery order. Random scenarios generated by the TypeScript core must produce byte-identical
  snapshots here.
- `interop/` runs Dart and TypeScript clients together against the real server, through a network
  that loses requests and responses, and checks every device ends with identical data. It runs in CI.
- [`example/field_app`](example/field_app): two agents, one dossier, on Android.

## Develop

Requires Flutter 3.44+ (Dart 3.12+).

```sh
flutter pub get
dart format --output=none --set-exit-if-changed .
flutter analyze
(cd packages/accordsync_core && dart test)
(cd packages/accordsync && dart test)
(cd packages/accordsync_flutter && flutter test)
interop/run.sh   # needs Docker and Node
```

`contract/` holds the golden vectors and protocol schemas from the Accord repository; every Dart
implementation must pass them. Refresh it with `dart run tool/sync_contract.dart` (reads `../app`,
or `ACCORD_APP_DIR`).
